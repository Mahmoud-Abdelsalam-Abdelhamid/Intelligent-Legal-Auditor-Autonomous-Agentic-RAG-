An enterprise-grade AI system designed to automate the initial review of SaaS contracts and Terms of Service. Unlike standard RAG chatbots that rely on simple semantic similarity, this system uses an **Agentic Workflow** to mimic the reasoning process of a human legal auditor.

---

## 🚀 Key Technical Achievements

### 🧠 Agentic Orchestration (LangGraph)
Built a custom state graph where nodes (Planner, Executor, Validator) share a global state. This allows the system to:
* **Maintain Context:** "Remember" failed search attempts.
* **Dynamic Adjustment:** Shift strategies mid-execution if initial queries fail.
* **Reasoning over Retrieval:** Moving beyond simple vector search to iterative analysis.

### 🔄 Self-Healing Logic
The system features a continuous feedback loop. If the **Validator** node detects a hallucination or an incomplete answer, it routes control back to the **Planner** with specific instructions (e.g., *"Search broader terms"*), creating a self-correcting cycle that ensures high-fidelity output.

### 🛠️ Robust Data Pipeline
* **Synonym Expansion:** Implemented a layer to catch jurisdictional variations in legal terminology (e.g., "Indemnification" vs. "Hold Harmless").
* **Efficient Indexing:** Advanced chunking strategies optimized for legal prose, embedded into **ChromaDB**.

### 🖥️ "Glass Box" Visualization
Developed a **Streamlit** dashboard that provides full transparency into the AI's "thought process." Users can see:
1. Exact search queries generated by the agent.
2. Specific document segments retrieved.
3. The logic behind the final **Risk Score** calculation.
