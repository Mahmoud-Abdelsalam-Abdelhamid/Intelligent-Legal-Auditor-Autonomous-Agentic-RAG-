# Intelligent-Legal-Auditor-Autonomous-Agentic-RAG-
Enterprise-grade Agentic AI for SaaS contract review. Built with LangGraph, it uses a self-healing state graph to mimic human auditing. Features: Synonym Expansion, ChromaDB ingestion, a Streamlit "Glass Box" UI, and model fallback for 99.9% uptime. Moving beyond RAG to autonomous, multi-agent reasoning.
